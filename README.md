# 振动 AI 实验助手

基于原始六状态动力学方程的科研辅助网页。手动调参、自然语言改参、文档参数核对与本地仿真共用同一套求解器。推荐赛道：科研创新。

## 长对话、分析图与高分辨率导出

右下角“AI连续提问”打开固定对话窗，页面记录可持续保留；上下文窗口可选最近20/50/100/200条，超过10万字符会提示新建对话。仿真状态显示排队、积分求解、统计分析和已完成步数。绘图设置支持六个状态的时域纵轴、任意状态相图投影、自定义坐标范围、PNG尺寸和72–1200 DPI。附加分析包括加速度、分窗RMS、位移分布、自相关和自定义状态投影。

## 界面优化

主界面为参数与结果图表，AI辅助工具移到图表下方并默认折叠，连续对话通过右下角按钮打开。详见界面与代码优化说明.md。

## 最快启动

Windows 安装 Python 3.10 或更新版本，双击 **安装并启动.cmd**。脚本创建本目录虚拟环境、安装依赖并打开浏览器。之后可双击 **启动.cmd**。

其他系统：

```bash
python -m venv .venv
# 激活虚拟环境后
python -m pip install -r requirements.txt
python app.py
```

浏览器将自动打开本次访问地址（默认 http://127.0.0.1:8765，端口被占用时自动选择空闲端口，以终端输出为准）。不要直接双击 index.html。首次启动使用原代码默认值 20000/12000/256，共512万积分步；页面不会自动运行。首次体验可主动点击“快速试算配置”。

## 功能与操作

- **手动模式**：编辑全部原模型参数，运行时域、频谱、相轨迹、庞加莱截面，导出抽样CSV与参数JSON。
- **模型配置**：快捷填写DeepSeek、DashScope、Kimi、SiliconFlow、OpenRouter、Ollama地址和示例模型，自行填写密钥与实际模型ID。真实可用性取决于账号、网络和模型权限。
- **连续对话**：“把 Epsilon33 改成0.04并运行”。改参会同步手动面板，含运行请求时调用本地求解器。也可输入“运行”使用当前参数。
- **扫频**：“对 Epsilon33 从0.02扫到0.08，做8点扫频”。6到60个等间距点，最多1200万积分步；不自动改动用户的周期与步数。
- **文档计划**：上传文本PDF、TXT、CSV、JSON、MD，检查本地提取文本，输入需求并解析。修改参数保留可核对引文；最多8组比较。计划可转入手动面板。
- **结果解释**：用已计算的参数和统计量追问模型。连续对话按所选窗口发送最近20/50/100/200条记录和最近最多8组统计量；刷新页面前请导出记录。
- **代理学习**：36组仿真，27组训练、9组留出评估，RBF核岭回归预测RMS并复算候选阻尼。本模块不需要模型API密钥。

## 密钥、文档与计算边界

密钥仅保留在当前网页内存及单次后端请求中，不写入报告或磁盘。模型调用将文本、参数、对话和统计量发送给用户所选服务商。刷新后重填密钥。不要把密钥写进需求、PDF或聊天。

曲线由本地数值求解器产生，模型只返回结构化操作或解释。程序不执行模型生成的任意代码。文档内容作为数据处理。相轨迹绘制真实状态y5与y6，图表为抽样显示。

暂不支持扫描PDF OCR、图片解析、新方程自动建模、真实单位自动标定、Lyapunov与混沌结论、运行中取消。模型语义理解仍可能出错，请核对参数。有限时长与步长的仿真不等于稳态或工程认证。

## 部署

本地版默认只监听127.0.0.1。公网文件已备齐：Dockerfile、compose.yaml、Caddyfile、.env.example。完整步骤见 **部署说明.md**，无服务器可见 **deploy-render.md**。

公网版用评审口令访问、HTTPS反向代理、单任务串行执行，最多等待3秒，计算默认180秒超时。云模型地址限定内置服务商，不提供公网自定义中转和本机Ollama。请勿关闭口令后当作大规模公共平台使用。

**公开源码仓库：https://github.com/ahzszq/vibration-ai-lab 。应用尚未在云平台实际部署，没有在线仿真Demo。** Docker配置已准备，当前环境无Docker，尚未构建镜像。测试覆盖本机HTTP、权限、仿真与模拟模型接口，不等同真实模型评测。
